# 문체 가이드

- 초등학교 고학년이 읽고 이해할 수 있는 수준으로 쓴다.
- 문장은 짧게 쓴다. 한 문장에 한 가지 사실만 담는다.
- 비유는 글 전체에서 1개를 넘지 않는다.
- 전문용어를 쉬운 말로 풀어 쓴다. 용어 자체의 뜻풀이(툴팁)는 코드가 따로 보여 주므로 본문에서 설명하지 않는다.
- 모르거나 판단할 수 없는 내용은 "모른다"고 쓰거나 언급하지 않는다. 추측해서 채우지 않는다.
- 입력으로 주어지지 않은 사실은 절대로 쓰지 않는다. 입력에 없는 숫자·비교·원인·평가를 만들어내지 않는다.
- 문체는 "~요"체(해요체)를 쓴다.
